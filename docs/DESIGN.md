# 设计稿 Design Spec

> 安全识别系统 SecurityVisionSystem —— 基于 YOLO26s-seg + PyQt5 的桌面端安防检测应用。

## 1. 设计目标

提供一个开箱即用的桌面端安全识别工具：接入图片 / 视频 / 摄像头，自动检测目标，
允许用户划定多边形 ROI（感兴趣区域），当目标进入 ROI 时立即多通道报警，
并实时呈现统计图表与异常帧回看。

## 2. 关键决策

| 维度 | 决策 | 说明 |
|------|------|------|
| 检测模型 | `yolo26s-seg.pt` | Small 规模，平衡精度与速度，CPU 可用 |
| 界面语言 | 中英双语 | 主界面中文，保留 ROI / Conf / IoU 等术语 |
| 数据源 | 图片 / 视频 / 摄像头 | 统一通过 cv2.VideoCapture 或文件读取 |
| ROI 绘制 | 多边形逐点点击 | 支持多个 ROI，双击/回车闭合 |
| 进入判定 | 检测框中心点在 ROI 内 | 误报少，最常用 |
| 报警通道 | 高亮+弹窗 / 声音 / 截图录像 / 日志 | 四通道独立开关 |
| 统计图表 | 柱状/折线/饼图/报警趋势 | pyqtgraph 实现 |
| 设计风格 | 工业实用风 | 单一钢蓝主题色，深色主题，无表情符号 |

### 主界面

│ [摄像头][图片][视频] 源:[下拉] [开始][暂停][停止]                   │ 工具栏

│                                  │ 识别筛选  ☑ person ☐ car ...    │

│   (标注帧 + ROI 叠加 + 红框高亮)  │ 实时状态   FPS 28 目标6 报警●   │ 右侧面板

### 设置界面（独立窗口，左侧分类导航）

- **检测**：置信度、IoU、设备(CPU/GPU)、模型选择、默认勾选类别
- **报警**：四通道开关、声音文件、截图/录像时长、冷却时间、弹窗开关
- **外观**：主题(深/浅)、字体大小、主题色
- **路径**：截图/录像/日志保存目录

## 4. 配色方案（克制工业风）

```
主题色(钢蓝)   PRIMARY    #2D6CDF   按钮/选中/ROI 线
主题色亮       PRIMARY_HI #4A86E8   悬停
主题色暗       PRIMARY_LO #1E4F9E   按下
报警色         ALARM      #D93025   进入ROI框/状态灯/弹窗
成功色         SUCCESS    #1E8E3E   就绪/正常
背景深         BG_DARK    #1E1F22   顶栏/画布
背景面板       BG_PANEL   #2A2D31   面板/对话框
文字主         FG_MAIN    #E8EAED
文字次         FG_SUB     #9AA0A6
边框           BORDER     #3C4043
```

主题色仅用于：主按钮、选中态、ROI 描边、关键数据。报警色仅用于：进入 ROI 的框、
报警状态灯、报警弹窗。其余一律灰阶。

## 5. 字体

- 中文：思源黑体 / 微软雅黑（系统回退）
- 英文/数字：JetBrains Mono（等宽，数据），正文 Segoe UI
- 字号：标题16 / 正文13 / 状态栏11 / 数据14 粗体
- 无任何 emoji，图标用统一线性 SVG（24px）

## 6. 交互流程

1. 选择数据源 → 工具栏切换 摄像头/图片/视频
2. 开始检测 → 启动 VideoWorker，画布显示实时标注
3. 绘制 ROI → 点"新建多边形" → 画布点击 → 双击闭合 → 可画多个
4. 目标进入 ROI → 该框描红 + 状态灯红 + 触发四通道报警
5. 类别筛选 → 右侧勾选实时生效
6. 异常帧 → 报警帧自动入列表，点击放大回看
7. 统计 → Tab 切换四种图表实时刷新
8. 设置 → 独立窗口配置，保存即时生效

## 7. 默认假设

- 设备默认 CPU（兼容性），有 NVIDIA GPU 可在设置切 CUDA
- 报警冷却默认 3 秒（同 ROI 同类目标），避免刷屏，可调
- 录像片段默认前后各 2 秒，可调
- 数据持久化用 csv（轻量，无需数据库）
