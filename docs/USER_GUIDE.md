# 使用手册 User Guide

## 1. 启动

```cmd
cd C:\Users\fu\Desktop\ultralytics\security-vision-system
.venv\Scripts\python.exe run.py
```

首次启动会从 `assets/models/yolo26s-seg.pt` 加载模型，CPU 下约 2-5 秒。

## 2. 界面总览

- **顶部菜单栏**：设置、关于
- **工具栏**：数据源切换（摄像头/图片/视频）、源选择、开始/暂停/停止
- **中央画布**：实时显示标注帧、ROI 叠加、红框高亮
- **右侧面板**：识别筛选、ROI 区域、实时状态
- **统计区**：四个 Tab 图表
- **异常帧列表**：报警帧缩略图
- **底部状态栏**：状态、FPS、当前源、时间

## 3. 数据源

### 摄像头
1. 工具栏选【摄像头】
2. 源下拉选设备号（默认 0）
3. 点【开始】即实时检测

### 图片
1. 工具栏选【图片】
2. 点【选择文件】选 jpg/png
3. 自动检测并显示标注结果

### 视频
1. 工具栏选【视频】
2. 选 mp4/avi 文件
3. 点【开始】逐帧检测，支持暂停/停止

## 4. ROI 区域（核心功能）

### 绘制多边形
1. 右侧【ROI 区域】点【新建多边形】
2. 鼠标移到画布，光标变十字
3. 依次单击标记顶点
4. 双击或按回车闭合多边形
5. 可重复绘制多个 ROI

### 管理
- ROI 列表显示每个区域（ROI1: 5点）
- 选中可删除单个
- 【清除】删除全部

### 报警触发
- 检测框**中心点**落入任意 ROI → 该框变红 + 状态灯红
- 同时触发勾选的报警通道（见设置）

## 5. 识别筛选

右侧【识别筛选】列出 COCO 80 类：
- 勾选 = 检测该类（默认仅 person）
- 取消 = 忽略该类
- 改动**实时生效**，无需重启

## 6. 统计图表

底部统计区四个 Tab：
- **类别柱状图**：各类累计检测数量
- **时间折线图**：目标数随时间变化（按小时/分钟分箱）
- **类别饼图**：各类占比
- **报警趋势**：报警次数随时间变化，识别高发时段

## 7. 异常帧

- 每次报警自动把当前帧存入列表（缩略图 + 时间 + 类别）
- 单击缩略图放大查看
- 原图保存于 `data/snapshots/`，录像片段存于 `data/clips/`

## 8. 设置（独立窗口）

菜单【设置】或工具栏齿轮图标打开，左侧分类：

### 检测
- 置信度阈值（0-1）：低于此值的目标被忽略，默认 0.45
- IoU 阈值（0-1）：NMS 重叠抑制，默认 0.5
- 推理设备：CPU / GPU（需 CUDA）
- 模型：可切换 yolo26n/s/m/l/x-seg
- 显示选项：掩码 / 框 / 标签 开关

### 报警
- 四通道开关：高亮 / 声音 / 截图 / 日志
- 声音文件：报警音 wav
- 冷却时间（秒）：同目标重复报警间隔，默认 3
- 录像前后时长（秒）：默认各 2
- 弹窗开关

### 外观
- 主题：深色 / 浅色
- 字体大小
- 主题色（4 预设）

### 路径
- 截图 / 录像 / 日志 保存目录

【保存】即时生效，【恢复默认】回退初始值。

## 9. 常见问题

**Q: 摄像头打不开？**
A: 检查设备号（0/1/2），确认无其它程序占用，权限允许。

**Q: 推理很卡？**
A: 1) 降低 imgsz；2) 换更小模型 yolo26n-seg；3) 有 GPU 在设置切 GPU。

**Q: 没检测到人？**
A: 调低置信度阈值；确认"识别筛选"勾选了 person。

**Q: 报警太频繁？**
A: 调大冷却时间（设置→报警→冷却时间）。

**Q: 数据在哪？**
A: `data/snapshots/`（截图）、`data/clips/`（录像）、`data/logs/`（日志 csv + app.log）。
